## Fase actual: Planificación de marca

### 1. Identidad

- [ ] Significado del nombre **11³** (narrativa, matemática, símbolo)
- [ ] Personalidad de marca (adjetivos, arquetipo, tono)
- [ ] Público objetivo (quién compra, dónde, por qué)
- [ ] Diferenciación vs. competencia (exótico / exclusivo — definición operativa)

### 2. Producto y materiales

- [ ] Líneas iniciales (anillos, collares, piezas únicas, etc.)
- [ ] Materiales prioritarios (oro 18k/24k, platino, diamantes — calidad, origen)
- [ ] Nivel de exclusividad (ediciones limitadas, made-to-order, one-of-one)
- [ ] Rango de precio orientativo (ultra-luxury, accessible luxury, etc.)

### 3. Experiencia y canal (conceptual)

- [ ] Cómo se descubre la marca (boutique, online, citas privadas, ferias)
- [ ] Ritual de compra / unboxing / certificación (concepto)
- [ ] Reglas de comunicación visual (referencias, no ejecutar diseño aún)

### 4. Operación (conceptual)

- [ ] Taller / proveedores / certificaciones (ideas, no contratos)
- [ ] Naming de colecciones (borrador)
- [ ] Restricciones éticas y de calidad (conflicto diamantes, trazabilidad, etc.)

### 5. Blueprint de marca (aprobación)

- [ ] Documento de posicionamiento de una página acordado
- [ ] **Fundador aprueba** salida de planificación → entonces definimos si hay fase técnica
