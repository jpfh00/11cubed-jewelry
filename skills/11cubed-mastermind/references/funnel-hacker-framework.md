# Funnel Hacker Framework (Russell Brunson / model what works)

Adapt Brunson's methodology for **11³ luxury jewelry**. Core idea: **don't guess — model structures that already converted**, then adapt with 11³'s exotic/exclusive soul.

---

## 1. The modeling loop (Tony Robbins style)

```
Find someone who has the result you want
    ↓
Reverse-engineer their FUNNEL (not just their logo)
    ↓
Extract the PRINCIPLE (why it worked)
    ↓
Adapt mechanism to YOUR market (11³)
    ↓
Test small → measure → iterate
```

**Model the structure, not the surface.** A jewelry drop is not a PDF funnel — but the *steps* (hook → nurture → offer → upsell) often rhyme.

---

## 2. Dream customer (avatar)

Before any funnel, define:

| Field | Question |
|-------|----------|
| Identity | Who do they want to become? |
| Pain | What frustration do they have with current jewelry options? |
| Desire | Status, uniqueness, gift, self-worth, art? |
| Watering holes | IG, TikTok, events, magazines, WhatsApp groups? |
| Already buying | Which brands do they already trust? |
| Objections | Price, trust, "is it real?", delivery, returns? |

One sharp avatar beats five vague personas.

---

## 3. Value ladder (jewelry adaptation)

Classic Brunson ladder adapted for luxury:

| Rung | Jewelry example | Purpose |
|------|-----------------|---------|
| Bait / lead magnet | Brand film, "how we source," care guide, waitlist | Trust + list |
| Frontend | Entry piece or deposit for bespoke consult | First transaction |
| Core offer | Signature collection piece | Main revenue |
| Premium | High jewelry / custom | Margin + prestige |
| Continuity / backend | VIP club, early access, annual private drop | LTV + referrals |

**11³ note:** At ultra-luxury, some rungs are **invitation-only** instead of public checkout.

---

## 4. Hook → Story → Offer (HSO)

Every campaign needs:

**Hook** — pattern interrupt in 3 seconds  
- Visual: exotic geometry, light on stone, not stock jewelry pose  
- Text: identity claim, not "20% off"

**Story** — epiphany bridge  
- Before: mass jewelry feels empty / everyone has the same  
- After: 11³ = rare object with meaning  
- Bridge: founder vision, craft, numbered edition, ritual

**Offer** — clear next step  
- Not "buy now" always — often **book private viewing**, **join waitlist**, **request piece X**

## 5. Funnel types to model (pick 1–2, don't boil ocean)

| Funnel type | Luxury jewelry use |
|-------------|-------------------|
| Waitlist launch | Hype → drop → sell-through story |
| Appointment funnel | Ad/story → apply → call → close |
| Hero piece + backend | One viral design → bespoke upsell |
| Event funnel | Trunk show RSVP → onsite → VIP follow-up |
| Influencer seed (micro) | 5 curators, not 500 micro-influencers |
| Content funnel | Craft ASMR / design process → email capture |

When user asks "model X," name the funnel type explicitly.

---

## 6. Funnel hacking checklist

When analyzing a competitor or reference brand:

1. **Traffic** — Where do they get attention? (paid, organic, PR, retail)
2. **Hook** — First thing you see; what emotion?
3. **Capture** — Email, SMS, waitlist, follow?
4. **Nurture** — Stories, emails, DMs, events?
5. **Conversion** — Checkout, appointment, deposit?
6. **Ascension** — Upsell, VIP, second purchase path?
7. **Economics** — AOV, frequency, CAC guess (if visible)

Document as a simple table in your response.

## 7. Brunson principles that transfer to 11³

| Principle | 11³ application |
|-----------|-----------------|
| Model what works | Study 2–3 successful exclusive jewelry launches |
| Sell transformation | "Become a collector of rare objects" |
| Stack value | Certificate + story + packaging + private access |
| Urgency (ethical) | Real edition limits, real appointment slots |
| Social proof | Collectors, press — not fake countdown timers |
| Follow-up funnels | VIP list is the asset; launch is the event |

---

## 8. What NOT to import from info-product funnels

- Aggressive false scarcity timers on every page  
- Long VSL tone for ultra-luxury (usually wrong fit)  
- Discount stacking culture  
- Generic "6-week course" energy — 11³ sells **objects and status**, not PDFs  

Use the **architecture**, not the tacky parts.

---

## 9. Metrics per funnel stage

| Stage | Metric |
|-------|--------|
| Hook | CTR, watch time, save rate |
| Capture | Waitlist cost per signup |
| Nurture | Email open (secondary), reply rate, appointment booked |
| Convert | Show rate, close rate, AOV |
| Ascend | Second purchase %, referral % |

## 10. Prompt for the mastermind

When advising, always ask:
> "Which successful brand's **funnel shape** is closest to what 11³ needs right now — and what part of their machine should we model first?"
