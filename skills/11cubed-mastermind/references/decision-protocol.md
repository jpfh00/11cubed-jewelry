# Decision Protocol — Quality Bar

Use this when formatting mastermind outputs and when the decision is high-stakes (positioning, pricing tier, first launch, brand pivot).

---

## Severity tiers

| Tier | Examples | Output depth |
|------|----------|--------------|
| **Quick** | "¿Te gusta este nombre?" | Veredicto + 3 bullets |
| **Standard** | Collection strategy, channel choice | Full template from SKILL.md |
| **Critical** | Brand pivot, price architecture, first public launch | Full template + funnel map + risks + assumptions log |

Ask yourself which tier applies; default to **Standard** for strategic questions.

---

## Funnel map (ASCII, when relevant)

```
[AWARENESS]  IG / PR / referral / event
      ↓ hook (identity + visual)
[CAPTURE]    waitlist / DM / appointment request
      ↓ story (11³ narrative)
[NURTURE]    email / private content / viewing invite
      ↓ offer (piece / edition / bespoke consult)
[CONVERT]    purchase or deposit
      ↓ ascend
[BACKEND]    VIP / next drop / referral
```

Include only the stages 11³ actually needs for the current phase.

## Trade-off matrix (when comparing options)

| Criterion | Weight for 11³ | Option A | Option B |
|-----------|----------------|----------|----------|
| Exclusivity preserved | High | | |
| Brand story strength | High | | |
| Speed to revenue | Medium | | |
| Capital required | Medium | | |
| Scalability | Low early | | |
| Funnel clarity | Medium | | |

Recommend the option that wins on **exclusivity + story** unless founder explicitly prioritizes speed.

## Assumption log

If data is missing, list assumptions explicitly:

```markdown
## Asumptions
- Market: [e.g. US + LATAM affluent, assumed]
- Price band: [assumed ultra-luxury $5k+ entry]
- Channel: [assumed appointment-first]
```

One follow-up question max — the sharpest missing variable.

---

## Anti-patterns in advice (self-check)

Before sending, verify you did **not**:
- [ ] Give 10 options without a recommendation  
- [ ] Ignore 11³ exclusivity positioning  
- [ ] Suggest mass-market discount tactics  
- [ ] Propose tech build in planning-only mode  
- [ ] Copy competitor identity instead of mechanism  
- [ ] Leave out "what NOT to do"
