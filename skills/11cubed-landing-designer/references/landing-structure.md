# Landing structure — 11³

> Section-level blueprint for the homepage. Adapt order only if funnel strategy (mastermind) requires it.

---

## Section reference

### 1. Hero

| Element | Guidance |
|---------|----------|
| Goal | Immediate **rarity + desire**; one focal object or abstract brand mark |
| Layout | Full viewport or 85vh; asymmetric text/image common |
| Copy | 3–8 word headline + one supporting line; no paragraph walls |
| CTA | Single primary (e.g. "Request private viewing") |
| Visual | Hero image or cinematic loop spec; dark or metal-toned grade |
| Avoid | Carousel of 5 products, countdown, dual CTAs competing |

### 2. Manifesto / Brand story

| Element | Guidance |
|---------|----------|
| Goal | Explain **why 11³** — exotic, not catalog |
| Copy | 2–4 short sentences; founder voice when available |
| Visual | Texture, macro craft, or typographic-only block |

### 3. Signature collection (teaser)

| Element | Guidance |
|---------|----------|
| Goal | Prove range without catalog overload |
| Count | 3–6 pieces on landing max |
| Card | Large imagery, minimal metadata (name + material hint) |
| Interaction | Hover reveal detail or link to piece page — no quick-buy on landing unless DTC confirmed |

### 4. Materials & craft

| Element | Guidance |
|---------|----------|
| Goal | Justify value tier through **materials and process** |
| Content | Diamonds, gold, atelier language — factual only |
| Visual | Macro shots, process stills, or illustrated diagram |

### 5. Exclusivity mechanism

| Element | Guidance |
|---------|----------|
| Goal | Make scarcity **credible** |
| Options | Edition of N, bespoke waitlist, invitation-only — use only confirmed model |
| Avoid | Fake "only 2 left" widgets |

### 6. Trust (quiet)

| Element | Guidance |
|---------|----------|
| Goal | Reduce risk for high-ticket consideration |
| Content | Certifications (GIA etc. only if true), press logos, atelier location |
| Tone | Small, monochrome logos; no testimonial carousel spam |

### 7. Private access CTA

| Element | Guidance |
|---------|----------|
| Goal | Capture **qualified intent** |
| Mechanisms | Form (name, email, message), Calendly embed spec, or mailto — per channel decision |
| Fields | Minimal; luxury buyers hate long forms on first touch |

### 8. Footer

| Element | Guidance |
|---------|----------|
| Content | Legal, contact, selective social, locale if applicable |
| Style | Low contrast, small type |

---

## Responsive behavior

| Breakpoint | Behavior |
|------------|----------|
| Mobile (&lt;768px) | Stack hero; sticky CTA optional but subtle |
| Tablet | Maintain hero impact; 2-column collection grid max |
| Desktop | Asymmetric layouts encouraged; max content width ~1200–1400px |

---

## SEO & meta (landing)

- Title: brand + differentiator (not "Home")
- Description: one sentence manifesto
- Structured data: `Organization` or `JewelryStore` only when business facts are confirmed
- hreflang: only if multi-market confirmed
